# DataPilot Analytics ??

**A Python-Based Desktop Application for Data Analysis, Reporting and Visualization**

## About the Project

DataPilot Analytics is a desktop application developed using Python. It helps users import datasets, explore data, generate reports and create visualizations through a simple graphical user interface.

## Features

- **Dashboard:** Displays key performance indicators such as total records, columns, revenue and profit.
- **Import Data:** Supports CSV and Excel files.
- **Data Overview:** Displays dataset information and column details.
- **Report Builder:** Generates reports using Sum, Mean, Average, Maximum, Minimum, Count and Median.
- **Chart Builder:** Creates Bar, Column, Line and Pie charts.
- **Export Reports:** Exports reports into Excel and CSV formats.
- **Export Charts:** Saves charts as PNG images.
- **Error Handling:** Handles empty files and unsupported file formats.

## Technologies Used

- Python
- Tkinter
- Pandas
- NumPy
- Matplotlib
- OpenPyXL
- PyInstaller

## How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib openpyxl
```

Run the application:

```bash
python main.py
```

## Windows Application

A standalone Windows executable was created using PyInstaller.
